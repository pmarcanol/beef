Privacy policy · Version 1.0 · Effective September 24, 2026

beef respects the code it reviews.

Beef is a pull-request review assistant. It processes only the GitHub pull request the user explicitly chooses to review.

Data beef handles

  • GitHub pull-request URL, title, description, author, labels, and branch metadata.
  • Changed filenames and unified diff content, including code from private repositories.
  • A user-provided TypeSafe API key.
  • Classifier results, usage totals, errors, and the latest review history.

How data is used and shared

When the user chooses Review, beef sends the selected pull-request metadata and diff content directly to TypeSafe AI over HTTPS solely to classify review priority. TypeSafe AI is the only external data recipient used by beef. Beef does not sell data, serve advertising, build user profiles, or allow its developer to read pull-request content.

Local storage and retention

The API key, latest run state, diff, and classifier output are stored locally using Chrome extension storage. Starting a new run replaces the previous run. The user can remove review history with Settings → Run history → Clear, remove the API key in Settings, or uninstall beef to remove extension storage.

Permissions

Beef accesses GitHub pull-request pages, opens the matching .diff page in an inactive tab, sends explicitly initiated classification requests to TypeSafe AI, and stores the resulting review locally. It does not access unrelated websites.

Limited use

Beef’s use and transfer of information is limited to providing and improving its single, user-facing pull-request review function. Data is not used for advertising, creditworthiness, or unrelated purposes.

Contact

Privacy and support questions can be sent through the support contact published on beef’s Chrome Web Store listing.
